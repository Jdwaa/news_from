# Развёртывание на bothost

Краткая инструкция для переноса бота на сервер. Полное описание проекта — в `README.md`.

## Что загружать

Загрузите **всё содержимое папки проекта**, кроме перечисленного ниже.

**Структура на сервере:**

```
main.py               точка входа
config.py             настройки и чтение окружения
channels.py           профили двух каналов (адреса, источники, промпты)
database.py           работа с SQLite
orchestrator.py       цепочка агентов
telegram_bot.py       команды и кнопки
memory_bank.py        память агентов (JSON)
image_store.py        хранение картинок
maintenance.py        бэкап и чистка
alerts.py             уведомления админу
net_utils.py          повторы при сбоях сети
console_utils.py      UTF-8 в консоли
agents/               агенты: парсер, селектор, рерайтер, редактор,
                      ревизор, картинки, публикатор, аналитик,
                      планировщик, воронка
requirements.txt      зависимости
test_*.py             тесты (можно не загружать, но полезны для проверки)
```

**Не загружать:** `.env` (секреты задаются в панели bothost), `news_bot.db` при первом
запуске (создастся сам), `memory_bank/` (создастся сам), `_backup_*/`, `__pycache__/`.

## Переменные окружения

Задаются в панели bothost. Обязательные:

| Переменная | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от @BotFather |
| `CHANNEL_ID` | id новостного канала (`-100...`) |
| `CHANNEL_TIPS_ID` | id канала лайфхаков (`-100...`) |
| `DEEPSEEK_API_KEY` | выбор новости, рерайт, редактура |
| `ODIROUTER_API_KEY` | генерация картинок |
| `ADMIN_ID` | ваш Telegram id — команды и уведомления |

Необязательные (значения по умолчанию подходят):

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `CHANNEL_USERNAME` | `Aioneway` | @username новостного канала |
| `CHANNEL_TIPS_USERNAME` | `aipolza_ii` | @username канала лайфхаков |
| `POST_INTERVAL` | 10800 | интервал новостного канала, сек |
| `POST_INTERVAL_TIPS` | = `POST_INTERVAL` | интервал лайфхаков, сек |
| `SCHEDULE_OFFSET_TIPS` | 3600 | сдвиг расписания лайфхаков, сек |
| `MIN_POST_LENGTH` | 300 | минимум новостного поста |
| `MAX_POST_LENGTH` | 950 | максимум новостного поста |
| `MIN_POST_LENGTH_TIPS` | 700 | минимум лайфхака |
| `MAX_POST_LENGTH_TIPS` | 2100 | максимум лайфхака |
| `MAX_REWRITE_ATTEMPTS` | 5 | попыток рерайта до публикации |
| `POST_COOLDOWN` | 600 | пауза между ручными запусками, сек |
| `MAX_POSTS_PER_DAY` | 8 | дневной лимит постов на канал |
| `CTA_EVERY_N_POSTS` | 3 | в каком по счёту посте призыв (0 — выключить) |
| `IMAGE_KEEP_DAYS` | 14 | чистка картинок, дней |
| `BACKUP_KEEP` | 7 | сколько копий БД хранить |
| `BACKUP_DIR` | `memory_bank/backups` | куда складывать бэкапы |
| `DB_PATH` | `news_bot.db` | путь к базе |
| `MEMORY_PATH` | `memory_bank` | папка памяти агентов |

**Важно про хранение:** `DB_PATH`, `MEMORY_PATH` и `BACKUP_DIR` задайте на
**постоянном диске**. Если хостинг пересобирает контейнер, данные в его файловой
системе могут пропасть — а в базе вся история, ссылки на посты и статистика.

## Команда запуска

```
python main.py
```

Нужен **Python 3.10+**. Установка зависимостей:

```
pip install -r requirements.txt
```

Если bothost сам ставит зависимости — укажите `requirements.txt` в настройках.

## Проверка после запуска

В логе должно появиться:

```
✅ Конфигурация в порядке
✅ База данных инициализирована
⏰ Запуск планировщиков публикаций...
   • «Новости ИИ» — интервал 3 ч, сдвиг 0 ч
   • «ИИ-лайфхаки» — интервал 3 ч, сдвиг 1 ч
🚀 Telegram-бот готов к работе!
```

Затем напишите боту `/status` — покажет статистику по обоим каналам.

## Команды бота

| Команда | Что делает |
|---|---|
| `/post` | выбор канала, затем публикация |
| `/post news` / `/post tips` | публикация сразу в канал |
| `/status` | посты, подписчики, просмотры по каналам |
| `/growth` | рост подписчиков и конверсия |
| `/analytics` | лучшее время публикации |
| `/pin` | поставить/обновить закреп-навигацию |
| `/admin` | очистка базы, перезапуск планировщиков |

## Что бот делает сам

- **Публикует** два канала по расписанию (новостной в свой час, лайфхаки на час позже)
- **Снимает метрики** подписчиков раз в час, пишет историю
- **Создаёт бэкап** базы раз в сутки, чистит старые копии
- **Убирает лишние картинки**: на диске хранится одна последняя (резерв)
- **Уведомляет админа** при сбое публикации, цикла или генерации картинок

## Частые вопросы

**Бот не отвечает.** Проверьте в логе строку «Telegram-бот готов к работе».
Если её нет — проблема с сетью или токеном. Если есть, но не отвечает —
возможно, запущен второй экземпляр на другой версии Python.

**Посты выходят без картинок.** В логе будет причина: либо генерация не удалась,
либо CDN не отдал файл. Бот берёт резервную картинку из предыдущего поста.

**Лимит публикаций.** `MAX_POSTS_PER_DAY` (по умолчанию 8) считает только реально
опубликованные посты с `message_id`. Если бот молчит — проверьте `⏳ Жду ещё N ч`.

**Проверить код после переноса.** Запустите `python test_final.py` — это основной
тест (54 проверки), не требует сети и не портит рабочую базу.
