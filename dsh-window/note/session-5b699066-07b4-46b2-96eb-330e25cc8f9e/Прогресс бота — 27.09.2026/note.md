# Прогресс: телеграм-бот «Новости ИИ» — 27.09.2026

Состояние на момент остановки: бот работает, всё закоммичено, тесты зелёные.

## Что сделано за сессию

### Два канала (главная задача)

Один бот ведёт два канала с разным продуктом:

| | `@Aioneway` (боевой) | `@aipolza_ii` (тестовый) |
|---|---|---|
| Продукт | Новости ИИ | Лайфхаки: как применить |
| Стиль | Футуристический | Инструкция «что мне с этого» |
| Источники | 33 (РФ + мир + лаборатории) | 25 (опыт применения) |
| Расписание | сдвиг +0 ч | сдвиг +1 ч |
| Лимит поста | 300–950 символов | 700–2100 символов |

Ключевой файл — `channels.py`: профили каналов, где собраны адрес, источники, промпт, интервал, лимиты, кросс-промо.

### Качество постов лайфхаков

Было 387–626 символов (пресно), стало ~1925. Причин было три:

1. Лимит длины был общий для каналов
2. Редактор резал пост по новостному максимуму **после** рерайтера
3. Промпт редактора требовал прогнозы и капс, запрещённые в лайфхаках — он ломал то, что просил рерайтер

### Воронка подписчиков

- Мониторинг роста: замеры каждый час, прирост, конверсия
- Кнопки под постами: «Подписаться», «Поделиться», «Источник»
- Закреп-навигация в обоих каналах
- Кросс-промо между каналами
- Призыв к действию в каждом 3-м посте (не чаще — иначе выглядит как реклама)

### Семь улучшений надёжности

1. **Ретраи API** (`net_utils.py`) — повтор только временных ошибок (5xx, таймаут), постоянные (401) сразу
2. **Уведомления админу** (`alerts.py`) — сбои планировщика, публикации, картинок
3. **Посты лайфхаков** — см. выше
4. **Статистика по лайфхакам** — аналитик брал `Config.CHANNEL_ID` для всех постов
5. **Обслуживание** (`maintenance.py`) — бэкап БД, чистка, суточная сводка
6. **Лимиты** — дневной максимум постов, считает только реальные публикации
7. **`/status`** — разбивка по каналам

### Картинки

Хранится **ровно один файл** (`image_store.py`): после успешной публикации удаляется, при неудаче остаётся резервом. Было 22 файла, 29 МБ и росло.

## Найденные и исправленные баги

- `skip_image_generation` — ручной запуск не делал картинку
- `TypeError` в кулдауне — naive минус aware время роняло `/post`
- Регулярка эмодзи ловила только `U+1F600–1F9FF` — не видела 🎧 💡 📌 ⚠️ (15 из 17)
- Аналитик собирал статистику обоих каналов по username первого
- Дневной лимит считал тестовые записи → блокировал публикации
- Закреп создавал дубли при повторном запуске
- Markdown ломался на `@aipolza_ii` (подчёркивание = курсив)
- `shutdown` не останавливал планировщики → процесс висел, lock оставался занят
- CDN-ссылки у OdiRouter живут 7 суток → картинки протухали
